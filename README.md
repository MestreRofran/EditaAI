# EditaAI 1.7 — editor de código

O **EditaAI** é um editor leve para escrever, revisar e testar páginas HTML e outros arquivos de código no celular ou no computador. A interface foi pensada para deixar o código em destaque, com ferramentas organizadas em botões compactos.

## O que você pode fazer

- **Editar código com realce de sintaxe:** cores para facilitar a leitura de HTML, CSS, JavaScript, JSON, XML/SVG, Markdown e texto simples.
- **Abrir arquivos do dispositivo:** carregue um arquivo existente e continue trabalhando nele.
- **Criar vários arquivos em abas:** alterne entre documentos sem precisar fechar o que está editando.
- **Desfazer e refazer:** recupere edições anteriores com os botões ou atalhos de teclado.
- **Buscar e substituir:** encontre um trecho, navegue pelos resultados e substitua uma ou todas as ocorrências.
- **Guardar histórico local:** crie pontos de recuperação e restaure versões anteriores.
- **Salvar em diferentes formatos:** exporte o conteúdo escolhendo o nome e a extensão, como HTML, TXT, CSS, JS, JSON, XML, SVG e outros formatos de texto.
- **Testar o resultado:** visualize o HTML dentro do app ou abra-o em outra aba. A prévia pode alternar entre modo automático, smartphone e computador.
- **Personalizar o editor:** escolha tema claro/escuro, ajuste o tamanho da fonte e use a numeração de linhas.
- **Usar como aplicativo instalado:** em navegadores compatíveis, o EditaAI pode ser adicionado à tela inicial e abrir em uma janela própria.

## Arquivos e privacidade

O rascunho, as abas e o histórico são mantidos no armazenamento local do navegador neste dispositivo. Eles não são sincronizados automaticamente entre aparelhos. Para manter uma cópia fora do navegador, use **Salvar** e guarde o arquivo exportado.

A pré-visualização permite executar scripts e usar cookies e armazenamento do navegador para testar páginas interativas. Execute apenas código em que você confia, pois esse código pode acessar dados disponíveis ao contexto da página de teste. Recursos que dependem de servidor, permissões ou serviços externos podem exigir um ambiente hospedado para funcionar completamente.

## Uso básico

Abra ou crie um arquivo, edite o código, use **Testar** para conferir o resultado e **Salvar** para exportar. Passe o mouse sobre um botão ou mantenha-o pressionado por um instante para ver uma explicação da sua função.
